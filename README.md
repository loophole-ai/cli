# Loophole CLI

This repository hosts release binaries for Loophole CLI. Source code is not kept here.

## Installation

**npm**

```bash
npm i -g @loophole-ai/cli
```

**Bun**

```bash
bun add -g @loophole-ai/cli
```

**curl**

```bash
curl -fsSL https://raw.githubusercontent.com/loophole-ai/forge/main/install.sh | bash
```

**Homebrew**

```bash
brew install loophole-ai/tap/loophole
```

## Manual download

Prebuilt binaries (`.exe`, `.zip`) for each version are available on the [Releases](../../releases) page.
